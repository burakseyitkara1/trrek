# trrek Phase 2 (v0.2.0) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scrub Video, external monitor brightness (DDC/CI), a welcome animation, and the polish left over from the 0.1.x reviews; finally a signed and notarized `v0.2.0`.

**Architecture:** The engine and settings model do not change (the scrub commands and the `externalMonitorBrightness` field already exist). Scrub is wired in `CommandDispatcher` to arrow key sending and to the overlay label. For external brightness, a testable DDC layer is added to `TrrekPlatform` (packet/checksum and display matching are pure functions, I/O sits behind private symbols) together with a `DisplayLocator` that finds the pointer's display; the dispatcher routes `stepBrightness` according to the pointer's display.

**Tech Stack:** Swift 6 (tools 6.0), Swift Testing, AppKit/SwiftUI (macOS 26), CoreGraphics, IOKit, private IOAVService (dlsym).

**Spec:** `docs/superpowers/specs/2026-11-03-trrek-design.md` (6.8, 6.9 — updated with this plan, 7.5, 7.6) and `docs/decisions.md`.

## Global Constraints

- `swift-tools-version: 6.0`, Swift 6 language mode, macOS 26 SDK; no Swift 6.3+ and no macOS 27 APIs; no `@State` (the local toolchain lacks the SwiftUI macro plugin; view state lives in models).
- Private symbols only in `PrivateSymbols.swift`, via `dlsym`; a missing symbol turns the feature off, it does not crash.
- No heap allocation on the frame path; no periodic timers; 0% CPU at idle, phys_footprint under 15 MB.
- No other app/library/project/product name appears in the project; code and UI are in English, documents in Turkish.
- Each task is on its own branch cut from main, with a PR; `make check` green; squash merge. Release with `make release VERSION=0.2.0`.

## Review Focus

1. If a DDC write/read fails (dock, HDMI, unsupported display), the brightness slide must not hang, the overlay must show "No DDC", and the built-in display must not be affected (Task 2 test `failedDDCShowsNoDDC`).
2. When the pointer is on the built-in display, the media key path must be used even if the external setting is on (Task 2 test `builtInScreenUsesMediaKeys`).
3. During scrub, a second finger/cancel must not send extra keys; ⌘ or another modifier must not remain held (Task 1 test `scrubCancelSendsNothing`).
4. Settings data with an older schema must not fall back to defaults in the new version; known fields must be kept (Task 3 test `decodesOlderSettingsBlobKeepingKnownFields`).
5. The welcome animation must leave no work in memory when the window closes (Task 3, the existing release test stays green).

### Task 2: External monitor brightness (DDC/CI)

**Files:** Create `Sources/TrrekPlatform/Display/DDCPacket.swift`, `Sources/TrrekPlatform/Display/DisplayServiceMatcher.swift`, `Sources/TrrekPlatform/Display/ExternalBrightness.swift`, `Sources/TrrekPlatform/Display/DisplayLocator.swift`; modify `PrivateSymbols.swift` (IOAVService: `IOAVServiceCreateWithService`, `IOAVServiceReadI2C`, `IOAVServiceWriteI2C`), `Pipeline/Ports.swift`, `Pipeline/CommandDispatcher.swift`, `Sources/Trrek/Coordinator.swift`, `Sources/Trrek/UI/EdgesTab.swift`, `Sources/TrrekAppCore/SettingsLabels.swift`; tests `Tests/TrrekPlatformTests/DDCPacketTests.swift`, `DisplayServiceMatcherTests.swift`, `CommandDispatcherTests.swift`.

**Interfaces:**
- `enum DDCPacket { static func setVCP(_ code: UInt8, value: UInt16) -> [UInt8]; static func getVCPRequest(_ code: UInt8) -> [UInt8]; static func parseGetVCPReply(_ bytes: [UInt8]) -> (current: UInt16, maximum: UInt16)? }` — DDC/CI packet (source 0x51, length | 0x80, opcode 0x03 set / 0x01 get, checksum = XOR of all bytes starting with the destination address 0x6E); reply validation (opcode 0x02, result code 0, checksum).
- `enum DisplayServiceMatcher { static func match(displays: [DisplayDescriptor], services: [ServiceDescriptor]) -> [CGDirectDisplayID: Int] }` — pure matching: first by manufacturer/product/serial from the EDID, then by order; representative dictionaries in tests.
- `public protocol ExternalBrightnessControlling: Sendable { func isExternal(display: CGDirectDisplayID) -> Bool; func step(display: CGDirectDisplayID, direction: Int, fine: Bool) -> Float? }` — `nil` = DDC failed.
- `public enum DisplayLocator { static func displayUnderPointer() -> CGDirectDisplayID? }`.
- `ExternalBrightness: ExternalBrightnessControlling` — finds the IORegistry `DCPAVServiceProxy` entries (with `Location` = External), `IOAVServiceCreateWithService`, caches the max/current value on first read, step `max/16` (fine `max/64`), write and a short wait (I2C delays are a one-time `usleep`, not on the frame thread: the dispatcher sends the DDC work to a serial `DispatchQueue` and updates the overlay from there).
- `CommandDispatcher(…, externalBrightness: (any ExternalBrightnessControlling)?, displayLocator: () -> CGDirectDisplayID?)` + `public var externalBrightnessEnabled: Bool`; `stepBrightness`: if the setting is on and the pointer is on an external display, DDC (overlay `.externalBrightness`, label "No DDC" on failure), otherwise the media key.
- `Coordinator` passes the setting to the dispatcher; the switch in the Edges tab becomes active (subtitle: "Monitors that support DDC/CI; the brightness edge follows the screen with the pointer").

- [ ] Tests: `setVCPPacketMatchesStandard` (0x10, 50 → known byte sequence and checksum), `parsesGetVCPReply`, `rejectsCorruptReply`, `matchesDisplaysByEDID`, `fallsBackToOrder`, `builtInScreenUsesMediaKeys`, `externalScreenUsesDDCWhenEnabled`, `externalDisabledUsesMediaKeys`, `failedDDCShowsNoDDC`, `ddcWorkRunsOffTheFrameThread` (`handle` returns immediately with a fake port delay).
- [ ] Implement, `make check`. Hardware: this Mac has no external display; a `TrrekProbe ddc list` command (prints the matched services and the brightness read) is added, plus an item in the manual test list.
- [ ] CHANGELOG, decision record (best effort, could not be verified). Commit `feat: control external monitor brightness over DDC/CI`, branch `feat/external-brightness`.
