# trrek Aşama 2 (v0.2.0) — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Video sarma (Scrub Video), harici monitör parlaklığı (DDC/CI), karşılama animasyonu ve 0.1.x incelemelerinden kalan cila; sonunda imzalı ve notarize edilmiş `v0.2.0`.

**Architecture:** Motor ve ayar modeli değişmez (scrub komutları ve `externalMonitorBrightness` alanı zaten var). Scrub, `CommandDispatcher`'da ok tuşu gönderimine ve overlay etiketine bağlanır. Harici parlaklık için `TrrekPlatform` içine test edilebilir bir DDC katmanı (paket/sağlama toplamı ve ekran eşleme saf fonksiyonlar, I/O private semboller arkasında) ve imleç ekranını bulan `DisplayLocator` eklenir; dağıtıcı `stepBrightness`'ı imlecin ekranına göre yönlendirir.

**Tech Stack:** Swift 6 (tools 6.0), Swift Testing, AppKit/SwiftUI (macOS 26), CoreGraphics, IOKit, private IOAVService (dlsym).

**Spec:** `docs/superpowers/specs/2026-11-03-trrek-design.md` (6.8, 6.9 — bu planla güncellendi, 7.5, 7.6) ve `docs/decisions.md`.

## Global Constraints

- `swift-tools-version: 6.0`, Swift 6 dil modu, macOS 26 SDK; Swift 6.3+ ve macOS 27 API'leri yok; `@State` yok (yerel araç zincirinde SwiftUI makro eklentisi eksik; görünüm durumu modellerde).
- Private semboller yalnızca `PrivateSymbols.swift` içinde, `dlsym` ile; eksik sembol özelliği kapatır, çökertmez.
- Kare yolunda heap ayırma yok; periyodik zamanlayıcı yok; boşta %0 CPU, 15 MB altı phys_footprint.
- Projede başka uygulama/kütüphane/proje/ürün adı geçmez; kod ve UI İngilizce, belgeler Türkçe.
- Her görev main'den açılan kendi dalında, PR ile; `make check` yeşil; squash merge. Yayın `make release VERSION=0.2.0`.

## Review Focus

1. DDC yazma/okuma başarısız olursa (dock, HDMI, desteklemeyen ekran) parlaklık slide'ı takılmamalı, overlay "No DDC" göstermeli ve dahili ekran etkilenmemeli (Görev 2 testi `failedDDCShowsNoDDC`).
2. İmleç dahili ekrandayken harici ayar açık olsa da medya tuşu yolu kullanılmalı (Görev 2 testi `builtInScreenUsesMediaKeys`).
3. Scrub sırasında ikinci parmak/iptal ek tuş göndermemeli; ⌘ ya da başka modifier basılı kalmamalı (Görev 1 testi `scrubCancelSendsNothing`).
4. Eski şemalı ayar verisi yeni sürümde varsayılanlara düşmemeli, bilinen alanlar korunmalı (Görev 3 testi `decodesOlderSettingsBlobKeepingKnownFields`).
5. Karşılama animasyonu pencere kapanınca bellekte iş bırakmamalı (Görev 3, mevcut serbest bırakma testi yeşil kalır).

### Görev 2: Harici monitör parlaklığı (DDC/CI)

**Files:** Create `Sources/TrrekPlatform/Display/DDCPacket.swift`, `Sources/TrrekPlatform/Display/DisplayServiceMatcher.swift`, `Sources/TrrekPlatform/Display/ExternalBrightness.swift`, `Sources/TrrekPlatform/Display/DisplayLocator.swift`; modify `PrivateSymbols.swift` (IOAVService: `IOAVServiceCreateWithService`, `IOAVServiceReadI2C`, `IOAVServiceWriteI2C`), `Pipeline/Ports.swift`, `Pipeline/CommandDispatcher.swift`, `Sources/Trrek/Coordinator.swift`, `Sources/Trrek/UI/EdgesTab.swift`, `Sources/TrrekAppCore/SettingsLabels.swift`; tests `Tests/TrrekPlatformTests/DDCPacketTests.swift`, `DisplayServiceMatcherTests.swift`, `CommandDispatcherTests.swift`.

**Interfaces:**
- `enum DDCPacket { static func setVCP(_ code: UInt8, value: UInt16) -> [UInt8]; static func getVCPRequest(_ code: UInt8) -> [UInt8]; static func parseGetVCPReply(_ bytes: [UInt8]) -> (current: UInt16, maximum: UInt16)? }` — DDC/CI paketi (kaynak 0x51, uzunluk | 0x80, opcode 0x03 set / 0x01 get, sağlama toplamı = hedef adres 0x6E ile başlayıp tüm baytların XOR'u); yanıt doğrulaması (opcode 0x02, sonuç kodu 0, sağlama toplamı).
- `enum DisplayServiceMatcher { static func match(displays: [DisplayDescriptor], services: [ServiceDescriptor]) -> [CGDirectDisplayID: Int] }` — saf eşleme: önce EDID'den üretici/ürün/seri, sonra sıra; testlerde temsilî sözlükler.
- `public protocol ExternalBrightnessControlling: Sendable { func isExternal(display: CGDirectDisplayID) -> Bool; func step(display: CGDirectDisplayID, direction: Int, fine: Bool) -> Float? }` — `nil` = DDC başarısız.
- `public enum DisplayLocator { static func displayUnderPointer() -> CGDirectDisplayID? }`.
- `ExternalBrightness: ExternalBrightnessControlling` — IORegistry `DCPAVServiceProxy` girdilerini (ve `Location` = External) bulur, `IOAVServiceCreateWithService`, ilk okumada maks/geçerli değeri önbelleğe alır, adım `maks/16` (fine `maks/64`), yazma ve kısa bekleme (I2C gecikmeleri tek seferlik `usleep`, kare thread'inde değil: dağıtıcı DDC işini seri bir `DispatchQueue`'ya gönderir ve overlay'i oradan günceller).
- `CommandDispatcher(…, externalBrightness: (any ExternalBrightnessControlling)?, displayLocator: () -> CGDirectDisplayID?)` + `public var externalBrightnessEnabled: Bool`; `stepBrightness`: ayar açık ve imleç harici ekrandaysa DDC (overlay `.externalBrightness`, başarısızsa etiket "No DDC"), değilse medya tuşu.
- `Coordinator` ayarı dağıtıcıya geçirir; Edges sekmesinde anahtar etkinleşir (alt yazı: "Monitors that support DDC/CI; the brightness edge follows the screen with the pointer").

- [ ] Testler: `setVCPPacketMatchesStandard` (0x10, 50 → bilinen bayt dizisi ve sağlama toplamı), `parsesGetVCPReply`, `rejectsCorruptReply`, `matchesDisplaysByEDID`, `fallsBackToOrder`, `builtInScreenUsesMediaKeys`, `externalScreenUsesDDCWhenEnabled`, `externalDisabledUsesMediaKeys`, `failedDDCShowsNoDDC`, `ddcWorkRunsOffTheFrameThread` (sahte port gecikmesiyle `handle` hemen döner).
- [ ] Uygula, `make check`. Donanım: bu Mac'te harici ekran yok; `TrrekProbe ddc list` komutu (eşlenen servisleri ve okunan parlaklığı yazdırır) eklenir, elle test listesine madde.
