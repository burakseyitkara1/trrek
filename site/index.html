Left edge

Top edge

Bottom edge

Keyboard backlight, by feel.

Slide along the bottom edge to set the backlight, with a level overlay to show where you are.

Corners are off until you give them an action: mute, a screenshot, Mission Control, Lock Screen or one of five more.

Made to feel like part of the Mac.

  • Edges per appGive an app its own edge actions. They apply while that app is in front; every other edge stays the same as everywhere else.
  • A haptic click for every stepYou feel each step of a slide, on the trackpad you are sliding on, so you never have to look.
  • Freeze CursorThe pointer stays still and scrolling pauses while you slide.
  • Hold-to-Slide keySlide only while a modifier key is held, or use it to switch the edges on and off.
  • Keeps itself up to dateOne click downloads, verifies and installs a new version in place.

No analytics. No accounts.

trrek has no identifiers either, and your settings stay on your Mac.

  • Signed and notarizedEvery release is signed with a Developer ID and notarized by Apple.
  • Open sourceMIT licensed; the code of every release is on GitHub.
  • One network requestA daily check for a new version, which sends trrek's version and nothing else. You can turn it off.
  • One permissionAccessibility, because trrek sends the same key and media events your keyboard would. It reads no window contents and logs no keystrokes.
