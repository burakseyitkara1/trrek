# Security Policy

## Supported versions

Only the latest release of trrek receives security fixes. trrek updates itself from the menu bar; please update before reporting.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue or pull request:

- Use GitHub's private vulnerability reporting for this repository (Security › Report a vulnerability).
- If that is not available, contact the maintainer through their GitHub profile, [burakseyitkara1](https://github.com/burakseyitkara1), and ask for a private channel before sharing details.

Include the trrek version, the macOS version, the steps to reproduce and what an attacker gains. You can expect an acknowledgement within a week. Please keep the report private until a fixed release is published; you will be credited in the changelog unless you prefer otherwise.
